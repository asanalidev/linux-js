Linux.js — это модульный фреймворк, эмулирующий ключевые системные подсистемы, виртуальную файловую систему (VFS), межпроцессное взаимодействие (IPC) и драйверы на чистом JS.

Быстрый старт и пример кода

Пакет полностью готов к работе в Node.js и легко подключается через стандартные модули.

консоль разработчика
$ npm install @asanalidev/linux-js

// Инициализация ядра и подсистем в вашем проекте
import { Kernel } from '@asanalidev/linux-js/kernel.js';
import { FileSystem } from '@asanalidev/linux-js/fs.js';

const fs = new FileSystem();
const kernel = new Kernel({ fs });

kernel.boot();
console.log("Linux.js успешно запущен!");
